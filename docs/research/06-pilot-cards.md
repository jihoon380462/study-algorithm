# 06. 재생 카드 견본 3장

장마다 붙을 "머릿속 재생 카드"가 어떤 모양인지 보이는 견본이다. 폰으로 싣고, 머릿속으로 돌리고, 폰으로 답을 맞춰 보는 용도다.

카드의 추적표와 정답은 전부 실제 실행 결과다(Python 3.13.18). 손으로 쓴 숫자는 없다. 생성 스크립트는 [data/pilot_cards.py](data/pilot_cards.py)에 있다.

과제는 두 종류다. 가벼움은 문장이나 공식을 떠올리는 것이고, 무거움은 상태를 끝까지 추적하는 것이다.

규약은 세 카드에 공통이다. 인덱스는 0부터 센다. 구간은 반열린 구간 `[lo, hi)`로 쓰고 `hi`는 포함하지 않는다.

## 카드 1. 선택 정렬

```python
def selection_sort(a):
    n = len(a)
    for i in range(n - 1):
        m = i
        for j in range(i + 1, n):
            if a[j] < a[m]:
                m = j
        a[i], a[m] = a[m], a[i]
    return a
```

- **불변식**: k번째 회전이 끝나면 앞의 k칸에는 가장 작은 k개가 순서대로 놓여 있고 다시 움직이지 않는다.
- **고정 입력**: `[3, 1, 4, 2]`

| # | 동작 | 그 뒤 배열 |
|---|---|---|
| 1 | 비교 a[1]=1 < a[0]=3 ? 예 → m=1 | [3, 1, 4, 2] |
| 2 | 비교 a[2]=4 < a[1]=1 ? 아니오 | [3, 1, 4, 2] |
| 3 | 비교 a[3]=2 < a[1]=1 ? 아니오 | [3, 1, 4, 2] |
| 4 | **교환** a[0] ↔ a[1] (1회전 끝) | **[1, 3, 4, 2]** |
| 5 | 비교 a[2]=4 < a[1]=3 ? 아니오 | [1, 3, 4, 2] |
| 6 | 비교 a[3]=2 < a[1]=3 ? 예 → m=3 | [1, 3, 4, 2] |
| 7 | **교환** a[1] ↔ a[3] (2회전 끝) | **[1, 2, 4, 3]** |
| 8 | 비교 a[3]=3 < a[2]=4 ? 예 → m=3 | [1, 2, 4, 3] |
| 9 | **교환** a[2] ↔ a[3] (3회전 끝) | **[1, 2, 3, 4]** |

- **대조할 답**: 비교 6번, 교환 3번. 회전이 끝날 때마다의 배열은 `[1, 3, 4, 2]` → `[1, 2, 4, 3]` → `[1, 2, 3, 4]`.
- **머릿속 과제**
  - 가벼움: 불변식 한 문장을 속으로 끝까지 말한다.
  - 가벼움: 원소가 4개면 비교는 몇 번인가? 답: 3 + 2 + 1 = 6번.
  - 무거움: `[3, 1, 4, 2]`를 돌려 회전이 끝날 때마다의 배열 세 개를 말한다.
- **변형 질문**: 입력이 이미 정렬된 `[1, 2, 3, 4]`이면 비교와 교환은 몇 번인가? 답: 비교 6번, 교환 3번(모두 제자리 교환). 선택 정렬은 입력이 정렬돼 있어도 일이 줄지 않는다.

원소를 4개로 잡은 이유: `[5, 2, 4, 1, 3]`처럼 5개면 비교 10번에 교환 4번으로 사건이 14개라, 머릿속 카드 상한(12개)을 넘는다.

## 카드 2. 이분 탐색

```python
def bsearch(a, t):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] == t:
            return mid
        if a[mid] < t:
            lo = mid + 1
        else:
            hi = mid
    return -1
```

- **불변식**: t가 리스트에 있다면 그 위치는 언제나 lo 이상 hi 미만이다.
- **고정 입력**: `a = [1, 3, 5, 7, 9]`, `t = 7`

| # | lo | hi | mid | a[mid] | 판단 |
|---|---|---|---|---|---|
| 1 | 0 | 5 | 2 | 5 | 5 < 7 → lo = 3 |
| 2 | 3 | 5 | 4 | 9 | 9 > 7 → hi = 4 |
| 3 | 3 | 4 | 3 | 7 | 7 == 7 → 찾음, 3 반환 |

- **대조할 답**: mid는 2 → 4 → 3 순서, 반환값은 3.
- **머릿속 과제**
  - 가벼움: 불변식과 `mid = (lo + hi) // 2`를 속으로 말한다.
  - 가벼움: 원소가 5개일 때 가장 많이 보는 경우는 몇 번인가? 답: 3번.
  - 무거움: `t = 4`(없는 값)일 때 (lo, hi, mid)의 변화와 반환값을 말한다. 답: (0, 5, 2) → (0, 2, 1) 뒤 lo와 hi가 같아져 끝나고, 반환값은 -1.
- **변형 질문**: `hi = mid`를 `hi = mid - 1`로 바꾸고 `t = 3`을 찾으면? 답: -1을 돌려준다. 3은 인덱스 1에 있는데 못 찾는다. 반열린 구간에서 hi는 이미 "포함하지 않는 끝"이라, 1을 더 빼면 한 칸을 건너뛴다.

## 카드 3. 스택으로 괄호 짝 맞추기

```python
PAIR = {")": "(", "]": "[", "}": "{"}

def balanced(s):
    st = []
    for ch in s:
        if ch in "([{":
            st.append(ch)
        elif not st:
            return False
        elif st.pop() != PAIR[ch]:
            return False
    return not st
```

- **불변식**: 스택에는 아직 짝을 만나지 못한 여는 괄호가 나온 순서대로 쌓여 있다.
- **고정 입력**: `"([]{})"`

| k | 글자 | 동작 | 그 뒤 스택 |
|---|---|---|---|
| 0 | `(` | push | `(` |
| 1 | `[` | push | `([` |
| 2 | `]` | pop `[` (짝 맞음) | `(` |
| 3 | `{` | push | `({` |
| 4 | `}` | pop `{` (짝 맞음) | `(` |
| 5 | `)` | pop `(` (짝 맞음) | (빔) |

- **대조할 답**: 결과 `True`, 스택이 가장 깊을 때 2칸, 끝났을 때 스택은 비어 있다.
- **머릿속 과제**
  - 가벼움: 불변식 한 문장을 속으로 끝까지 말한다.
  - 가벼움: 닫는 괄호가 왔는데 스택이 비어 있으면? 답: 바로 `False`. 예: `"())"`는 인덱스 2에서 끝난다.
  - 무거움: `"{[()]}"`를 돌려 스택이 가장 깊을 때의 칸 수와 결과를 말한다. 답: 3칸, `True`.
- **변형 질문**: `"([)]"`와 `"(()"`는 각각 어디서 어떻게 끝나는가? 답: `"([)]"`는 인덱스 2에서 `)`가 왔는데 꼭대기가 `[`라서 `False`. `"(()"`는 끝까지 가지만 스택에 `(`가 남아 `False`. 마지막 줄이 `return True`가 아니라 `return not st`인 이유다.
