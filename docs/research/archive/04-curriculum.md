# 04. 난이도 규칙과 챕터 지도

조사일 2026-11-23. 원자료는 [data/curriculum-roadmap.json](../data/curriculum-roadmap.json)과 [data/curriculum-reviews.json](../data/curriculum-reviews.json)에 있다.

## 1. 요약

- 처음 만든 80장 초안을 두 가지 관점(선수 관계와 경사, 머릿속 재생 가능성)으로 따로 비판 검토했다. 두 검토 모두 **약 140~150개 단위**로 늘려야 한다고 결론 냈다. 여기 실은 지도는 153개 항목이다(본편 103, 다리 21, 복습 16, 쉬어 가기 7, 부록 6).
- 늘어난 이유는 "한 장에 새 개념 하나"를 실제로 지켰기 때문이다. 한 단위는 카드 한 장, 2~5분 분량이다. 장이 많아진 것이 아니라 계단이 낮아진 것이다.
- **1판은 첫 14장이다.** 두 검토가 이 구간의 내용에 거의 일치했다.
- 15장부터는 지도다. 한 번에 한 장씩 만들고, 순서는 1판을 실제로 써 본 뒤 확정한다.
- 난이도 숫자와 임계값은 사람이 매긴 초안이다. 실제 경사는 장을 만들 때 코드와 추적에서 잰 값으로 확인한다.

## 2. 80장 초안에서 드러난 문제

두 검토가 공통으로 찾은 것이다.

1. **묶음 장.** 20여 개 장이 새 개념을 2~5개씩 담았다(예: 버블 정렬 + 안정성 + `sorted(key=)`가 한 장).
2. **가르친 적 없는 선수 지식.** 중첩 루프, 2차원 리스트, `class`, 문자열, 이진수, 동시 대입을 설명 없이 썼다.
3. **묵은 선수 지식.** 선수 장이 19~66장 앞에 있는 곳이 17군데였고 복습 장은 0개였다.
4. **끊긴 다리.** 메모이제이션과 DP 표 사이가 34장이었다. Hello Algo와 Wengrow는 둘을 연달아 둔다.
5. **낙관적인 재생 판정.** 실제로 세어 보면 머릿속 카드 상한(12사건)을 넘는 예제가 많았다.

   | 예제 | 실제로 센 값 |
   |---|---|
   | 선택 정렬, 원소 5개 | 비교 10 + 교환 4 = 14 |
   | 삽입 정렬 `[5,2,4,1,3]` | 16 |
   | 요세푸스 (7, 3) | 21 |
   | `fib(5)` | 호출 15번 |
   | LIS, 원소 8개 | 비교 28번 |
   | 4-Queens | 호출 17번 |
   | 플로이드, 정점 3개 | 검사 27번 |

6. **위치를 따라 매긴 난이도.** 구간 병합과 N-Queens가 같은 6이었다. "인접 차 1 이하를 만족한다"는 주장이 순환 논증이었다.
7. **CPython과 다른 서술.** `dict`는 체이닝이 아니라 개방 주소법이다. `list` 용량은 2배씩 늘지 않는다(3.13 실측 4 → 8 → 16 → 24 → 32). `heapq`의 최대 힙 함수는 3.13에 없다. 교재용 모델로 가르칠 때는 모델임을 밝힌다.
8. **규격을 넘는 코드.** 격자 BFS가 18줄에 49자, 2차원 DP의 한 줄이 46~53자였다. 4칸 들여쓰기로 3단 중첩이면 한 줄에 남는 폭은 24자 안팎이다.

## 3. 난이도 규칙

"완만하게"를 검사할 수 있는 형태로 바꾼 것이다. 장마다 메타데이터를 적고 스크립트(`check_gradient.py`)로 확인한다.

| # | 규칙 | 기준 |
|---|---|---|
| 1 | 새 개념 수 | 장마다 새 개념 정확히 1개(복습 장은 0개). 새 Python 문법·내장 함수·import는 1개 이하. 쓰는 개념은 모두 앞 장에서 도입 |
| 2 | 난이도 상승 폭 | 직전 3개 장의 최고값 + 1 이하, 지금까지의 최고값 + 1 이하. 내려가는 것은 제한 없음 |
| 3 | 꼭대기 연속 | 난이도 4 이상에서, 지금까지의 최고 난이도인 장은 3연속까지 |
| 4 | 제어 구조 단계 | 0 직선, 1 단일 루프, 2 중첩 루프·두 인덱스, 3 스택·큐·힙이 모는 루프, 4 선형 재귀, 5 갈래 재귀, 6 재귀 + 되돌리기. 인접 장 +1까지 |
| 5 | 증명 부담 | 0 없음, 1 불변식 한 줄, 2 교환 논증·귀납, 3 분할 상환. 인접 장 +1까지. 제어 구조 단계와 같은 장에서 함께 오르지 않음 |
| 6 | 머릿속 재생 예산 | 대표 입력을 계측 코드로 실행해 등급을 기계적으로 정함. 머릿속: 원소 5개, 변수 3개, 사건 12개 이하. 머릿속(힘듦): 칸 9개, 변수 5개, 사건 20개 이하. 넘으면 종이 필요 |
| 7 | 코드 규격 | 핵심 함수 15줄, 줄당 40자(36자 권장), 중첩 3단 이하. 인접 장 대비 +5줄 이내. 넘으면 장을 나눔 |
| 8 | 선수 지식 | 선수 장 3개 이하. 그중 하나는 최근 10장 안. 아니면 장 첫 화면에 30초 회상 상자(선수 장의 공식과 고정 입력) |
| 9 | 복습 간격 | 복습 장 사이의 본편 장은 12개 이하 |
| 10 | 숨 고르기 | 쉬는 장 없이 이어지는 본편은 7장 이하. 머릿속 재생이 안 되는 장은 5연속 이하 |
| 11 | 카드 형식 | 재귀 장은 정의 카드(하는 일 한 문장, 기저, 한 줄). 호출 스택 추적은 다리 장에서 깊이 3까지. DP 장은 표 카드 4줄(칸의 뜻, 점화식, 초기값, 채우는 순서) |
| 12 | 사용 먼저, 구현 나중 | `dict`·`set` 사용 → 해시 내부, `heapq` 사용 → 힙 내부, `deque` 사용 → 연결 리스트 |
| 13 | 추상화가 처음 나오는 장 | 값을 인덱스로, 답의 범위를 탐색, 집합을 정수로, 암묵적 그래프 같은 발상이 처음 나오는 장은 다른 축을 올리지 않음 |
| 14 | 정답의 출처 | 카드의 정답과 추적표는 실제 실행 결과와 일치. 문자열 해시값이나 `set` 순서에 기대는 추적은 쓰지 않음 |

운영 규칙도 둔다. 한 장에 사흘 넘게 머물거나 두 장 연속 "막혔다"를 누르면, 다음 장으로 가지 않고 그 사이에 다리 장을 하나 끼운다.

규칙 2는 "쉬는 장 다음에 원래 높이로 돌아오는 것"을 허용한다. 예를 들어 난이도 3 → 복습 2 → 4는 통과다. 복습 장은 계단이 아니라 층계참이기 때문이다.

그 결과 바로 앞 장보다 2 높은 장이 6곳 남아 있다(15, 58, 94, 120, 126, 129장). 모두 쉬어 가는 장, 복습 장, 다리 장 바로 다음이다. 실제로 써 보고 버겁다면 그 앞에 다리 장을 넣는다.

## 5. 두 검토가 갈린 곳

지도는 선수·경사 검토의 순서를 기준으로 삼았다. 묵은 선수 지식이 더 적고(가장 가까운 선수 장이 10장보다 먼 장이 19개 대 34개, 같은 기준으로 직접 셈) 복습 장이 규칙적으로 들어 있기 때문이다. 머릿속 재생 검토의 측정값과 대안은 장을 만들 때 반영한다.

| 삽입 정렬 | 1판 뒤(18장) | 1판 안 |

어느 쪽이 맞는지는 조사로 정할 수 없다. 1판 14장을 실제로 써 본 기록(통과율, "막혔다" 표시)으로 15장 이후를 확정한다.

## 6. 1판: 첫 14장

입력과 답은 Python 3.13에서 실행해 확인한 값이다.

### 1. 추적표 — 한 줄씩 실행하고 바뀐 칸만 고쳐 쓰기
- 난이도 1 · 본편 · 머릿속
- 새 개념: 추적표(변수마다 고정 칸을 둔 메모리 표)로 실행을 따라가는 절차
- 외울 것: 한 줄 실행 → 바뀐 변수 칸만 갱신. range(a, b) = a, …, b-1
- 고정 입력: s = 0; for i in range(1, 5): s += i → s: 1, 3, 6, 10 (답 10)

### 2. while과 동시 대입 — 우변을 먼저 다 계산한다
- 난이도 1 · 본편 · 머릿속 · 선수 1장
- 새 개념: 동시 대입: 우변을 옛 값으로 모두 계산한 뒤 한꺼번에 대입(swap 포함)
- 외울 것: a, b = b, a + b → 새 a = 옛 b, 새 b = 옛 a + 옛 b. swap: x, y = y, x
- 고정 입력: a, b = 1, 1에서 3번 반복 → (1, 2) → (2, 3) → (3, 5)

### 3. 유클리드 호제법 — 숫자 두 개로 도는 첫 알고리즘
- 난이도 2 · 본편 · 머릿속 · 선수 2장
- 새 개념: 나머지로 문제를 줄인다: gcd(a, b) = gcd(b, a % b)
- 외울 것: while b != 0: a, b = b, a % b → 끝나면 a가 답. gcd(a, 0) = a
- 고정 입력: (48, 18) → (18, 12) → (12, 6) → (6, 0) → 6

### 4. list 인덱스와 반열림 구간 [l, r)
- 난이도 1 · 본편 · 머릿속 · 선수 1장
- 새 개념: 반열림 구간: 끝 인덱스는 포함하지 않는다
- 외울 것: len(a[l:r]) = r - l, 마지막 원소는 a[r-1], a[-1] = a[len(a)-1]
- 고정 입력: a = [5, 2, 4, 1, 3] → a[1:4] = [2, 4, 1] (길이 3), a[-1] = 3

### 5. 이름과 객체 — b = a는 복사가 아니다
- 난이도 2 · 본편 · 머릿속 · 선수 4장
- 새 개념: 별칭: 한 객체에 이름이 둘. 복사는 a[:]
- 외울 것: b = a → 같은 객체에 이름표 하나 더. b = a[:] → 새 객체
- 고정 입력: a = [1, 2]; b = a; c = a[:]; b.append(3) → a = [1, 2, 3], c = [1, 2]

### 6. 함수 호출 추적 — 인자는 이름표, return은 값
- 난이도 2 · 본편 · 머릿속 · 선수 5장
- 새 개념: 호출하면 새 지역 이름이 같은 객체에 붙는다(프레임 1개)
- 외울 것: 매개변수 = 인자 객체의 새 이름. 재대입은 지역에서만, 변경(append)은 호출자에게도 보인다
- 고정 입력: def f(x): x.append(0); x = [9] / a = [1]; f(a) → a = [1, 0]

### 7. 루프 불변식 — 지금까지 본 것 중 최댓값
- 난이도 2 · 본편 · 머릿속 · 선수 4, 6장
- 새 개념: 루프 불변식: 매 반복 직전에 항상 참인 한 문장
- 외울 것: best = a[0]으로 시작. i = 1..n-1 반복 직전: best == max(a[:i])
- 고정 입력: [3, 1, 4, 1, 5] → best: 3, 3, 4, 4, 5 (초기값 3 뒤 갱신 2번)

### 8. 선형 탐색 — 찾으면 바로 멈추기
- 난이도 2 · 본편 · 머릿속 · 선수 7장
- 새 개념: 조기 종료와 최선/최악 비교 횟수
- 외울 것: 비교 횟수: 최선 1번, 최악 n번(없으면 n번 보고 -1)
- 고정 입력: [5, 2, 4, 1, 3]에서 4 → 3번 비교, 인덱스 2. 7 → 5번 비교, -1

### 9. 중첩 루프 — 모든 쌍 (i, j) 훑기
- 난이도 3 · 다리 · 머릿속 · 선수 8장
- 새 개념: 중첩 루프: 바깥이 한 번 돌 때 안쪽은 처음부터 끝까지
- 외울 것: i < j인 쌍의 수 = n(n-1)/2
- 고정 입력: [1, 4, 2, 3]: 쌍 6개 중 합이 5인 것은 값 (1, 4)[인덱스 (0, 1)], 값 (2, 3)[인덱스 (2, 3)] → 2개

### 10. 연산 횟수 세기 — n과 n²
- 난이도 3 · 본편 · 머릿속 · 선수 8, 9장
- 새 개념: 증가율로 분류하기(Big-O 직관)
- 외울 것: 루프 하나 → n번 → O(n). 모든 쌍 → n(n-1)/2번 → O(n²). n이 2배면 n²은 4배(쌍의 수는 6 → 28로 약 4.7배)
- 고정 입력: n = 4: 4번 / 6쌍. n = 8: 8번 / 28쌍

### 11. 이분 탐색 — 절반 버리기
- 난이도 3 · 본편 · 머릿속 · 선수 4, 8, 10장
- 새 개념: 정렬된 배열의 가운데를 보고 절반을 버린다
- 외울 것: 불변식: 답이 있다면 a[lo:hi] 안. mid = (lo + hi) // 2. a[mid] < x면 lo = mid + 1, 크면 hi = mid
- 고정 입력: a = [1, 3, 5, 7, 9], x = 7 → (lo, hi, mid): (0, 5, 2) → (3, 5, 4) → (3, 4, 3) 발견, 3번

### 12. log n — 몇 번 절반으로 나눌 수 있나
- 난이도 3 · 본편 · 머릿속 · 선수 10, 11장
- 새 개념: log₂ n = 1이 될 때까지 절반으로 나누는 횟수
- 외울 것: 2¹⁰ = 1024 ≈ 10³. 이분 탐색 최대 확인 횟수 = ⌊log₂ n⌋ + 1
- 고정 입력: 16 → 8 → 4 → 2 → 1: 나누기 4번(확인은 최대 5번). n = 1000이면 최대 10번 확인

### 13. 선택 정렬 — 남은 것 중 최솟값을 앞으로
- 난이도 3 · 본편 · 머릿속 · 선수 2, 7, 9장
- 새 개념: 정렬된 앞부분을 한 칸씩 늘린다(최솟값 찾기 + swap)
- 외울 것: i회전 후: a[:i]는 가장 작은 i개가 최종 위치. 비교는 항상 n(n-1)/2번
- 고정 입력: [3, 1, 4, 2] → [1, 3, 4, 2] → [1, 2, 4, 3] → [1, 2, 3, 4] (비교 6, swap 3)

### 14. 체크포인트 1 — V1 카드 섞어 떠올리기
- 난이도 2 · 복습 · 머릿속 · 선수 3, 5, 11, 13장
- 새 개념: 새 개념 없음: 1~13장 카드를 섞어 인출
- 외울 것: 카드 한 장 = 불변식 한 문장 + 고정 입력의 답 + '이 줄을 바꾸면?'
- 고정 입력: gcd(48, 18) = 6 / [1, 3, 5, 7, 9]에서 7 → 3번 / [3, 1, 4, 2] 선택 정렬 2회전 후 [1, 2, 4, 3]

## 8. 저장 형식 제안

지도는 `curriculum.json` 한 파일로 두고, 장을 만들 때마다 잰 값을 채운다.

```json
{
  "n": 13,
  "slug": "selection-sort",
  "kind": "core",
  "introduces": ["선택 정렬"],
  "requires": [2, 7, 9],
  "difficulty": 3,
  "control": 2,
  "proof": 1,
  "card": "trace",
  "input": [3, 1, 4, 2],
  "measured": {"events": 9, "vars": 3, "loc": 9, "width": 33},
  "status": "draft"
}
```

`measured`는 사람이 쓰지 않는다. 빌드가 실제 실행과 코드에서 채운다. `status`는 초안, 검증 통과, 학습 통과의 세 단계로 둔다.

## 9. 한계

- 난이도 숫자는 검토자가 손으로 매겼다. 규칙 통과가 곧 "쉽다"는 뜻은 아니다.
- 임계값(10장, 12장, 3연속, 12사건)은 근거 있는 추정이지 측정값이 아니다. 1판을 돌린 뒤 보정한다.
- 15장 이후의 재생 등급(머릿속 113개 등)은 검토자의 판단이다. 장을 만들 때 계측 실행으로 다시 정한다.
- 두 검토는 같은 모델이 관점만 달리해 수행했다. 사람 교사의 검토를 거친 순서가 아니다.
- 교차 점검에서 나온 지적 20건을 반영했다(재생 등급 하향 7개 장, 다리 장 2개 추가, 쉬는 장 2개 이동, 교재용 모델 표시 3개 장 등). 점검은 1~30장의 선수 지식과 대표 입력의 답에 집중했고, 31장 이후의 Python 기능 도입 순서와 코드 규격은 확인하지 못했다.
- `dict`·`list` 내부를 다루는 장은 실제 CPython과 다른 교재용 모델을 쓴다. 장에 그 사실을 적는다.
- 머릿속 재생이 실제로 되는 크기인지는 1판을 써 봐야 알 수 있다.
