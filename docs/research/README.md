# 시작 전 조사 정리

Python 코드로 배우는 시각적인 알고리즘·자료구조 교재를, 혼자 쓰는 모바일 사이트로 만들기 전에 한 조사다. 조사일은 2026-11-23이다.

요청은 세 가지였다. 내가 놓치고 있는 것 찾기, 학습 사이트용 SKILL.md를 모아 공통 기능 추리기, 전체 정리.

## 1. 결론

1. **만들 것은 "보는 사이트"가 아니라 "재생 카드"다.** 실제 사용은 휴식 때 싣고, 작업 중 머릿속으로 돌리고, 다음 휴식 때 확인하는 순서다. 조사한 사이트·교재·스킬 가운데 이 용도로 설계된 것은 없었다.
2. **"난이도를 완만하게"는 숫자 규칙과 검사 스크립트로만 지켜진다.** 80장 초안을 두 관점으로 검토하니 약 150개 단위로 쪼개야 했다. 1판은 첫 14장이다.
3. **추적표와 정답은 실제 실행에서만 만든다.** 에이전트가 손으로 쓴 추적은 틀리고, 혼자 쓰는 교재에서는 틀린 것을 그대로 외우게 된다.
4. **그대로 쓸 수 있는 SKILL.md는 없다.** 패턴만 가져와 프로젝트 전용 스킬을 쓴다. 이 프로젝트에 가장 필요한 기능이 기존 스킬에서는 가장 드물었다.
5. **1판은 작게 만든다.** Python 빌드 스크립트 하나와 의존성 없는 플레이어 하나다. 사이트 프레임워크, PWA, 적응형 복습, 브라우저 안 Python은 미룬다.
6. **가장 큰 위험은 기술이 아니다.** 도구만 만들고 공부는 안 하는 것, 속으로만 떠올려서 효과가 약한 것, 작업 중 주의 분산이다.
7. **코드를 쓰기 전에 종이 카드 3장으로 3근무일 써 본다.** 카드는 [06](06-pilot-cards.md)에 실행 결과로 만들어 두었다.

## 2. 놓치고 있는 것 10가지

전체 33개와 근거는 [01-blind-spots.md](01-blind-spots.md)에 있다.

1. 학습은 화면 밖에서 일어난다. 장마다 재생 카드가 필요하다.
2. 보기만 해서는 늘지 않는다. 먼저 예측하고 나서 확인하게 만든다.
3. 속으로만 떠올리면 효과가 약할 수 있다. 답을 한 덩어리로 만들고, 폰을 볼 때 탭으로 답을 고른 뒤 정답을 연다.
4. 머릿속 재생에는 크기 한계가 있다. 원소 5개, 변수 3개, 12스텝 이하로 묶는다.
5. 재귀와 DP는 추적으로 외울 수 없다. 카드를 추적, 정의, 표의 세 종류로 나눈다.
6. 머릿속 추적은 주의를 쓴다. 멈춰서 대기할 때만 하고, 가벼움·무거움 등급을 둔다. 사업장 규정이 먼저다.
7. 폰을 실제로 얼마나 볼 수 있는지가 설계를 정한다. 확인 전까지는 "휴식 시간에만"으로 가정한다.
8. 급경사 지점은 이미 알려져 있다. 반복문에서 재귀, 재귀에서 DP 표 같은 곳마다 다리 장을 놓는다.
9. AI는 내가 배우는 속도보다 빨리 만든다. 통과한 장 + 2까지만 만들고, 한 세션에 한 장만 만든다.
10. 폰으로 만드는 흐름을 먼저 깔아야 한다. 미리보기 주소, 저장소 안의 규칙 파일, 자동 검증이 필요하다.

## 3. SKILL.md 공통 기능

스킬 후보 164건을 모아 36개를 원문으로 정독했다. 상세는 [02](02-skill-md-common-features.md), 스킬별 메모는 [02b](02b-skill-notes.md)에 있다.

**과반이 갖춘 것**(원문을 확보한 35개 중 명시한 수)
- 짧은 SKILL.md와 참조 파일·스크립트로 나눈 포장: 22
- 완료 전 검증 게이트: 21
- 고정된 장 골격: 17
- 실제 실행·실제 출처만 쓰는 정확성 게이트: 16
- 먼저 맞히고 나서 공개, 끝에 자가 점검: 각 13
- 한 화면 한 개념과 숫자 상한, 템플릿 먼저: 각 12

**드물지만 이 프로젝트의 핵심인 것**
- 모바일 수치 규칙: 6
- 선수 순서 검증, 스텝을 데이터로, 가장 작은 예제의 전체 상태, 수업과 분리된 요약 카드, 난이도 수치 보정, 오프라인: 각 4
- 의미 색 토큰: 2

**그대로 가져오면 안 되는 것**: 데스크톱 전제(hover, 좌우 2단), CDN 의존, 주제마다 바뀌는 테마, 승인 없이 바로 만들기, 무관한 지시(저장소 star 유도 등), 비영리·동일조건 라이선스.

## 4. 조사 중에 뒤집힌 것

1차 조사의 주장 42건을 1차 자료로 다시 확인했다(확인 32, 부분 확인 10). 계획이 달라진 것만 추린다. 전체는 [07](07-sources.md)에 있다.

- **백준**: "종료했다"가 아니다. 2026-04-28에 종료했다가 운영사가 바뀌어 2026-11-20에 다시 열렸다. 그래도 교재는 자체 예제로 완결한다.
- **Hello Algo의 사이트 스택(MkDocs Material)**: 유지보수 모드이고 2027-05-05에 수명이 끝난다. 따라 하지 않는다.
- **브라우저에서 같은 추적기 돌리기**: MicroPython으로는 지역 변수를 읽을 수 없어 안 된다.
- **"머릿속 재생이면 충분하다"**: 여러 요소로 된 자료에서는 속으로 떠올리기가 다시 읽기와 차이가 없었다는 연구가 있다.
- **"적지 않으면 정답률이 82%에서 61%로 떨어진다"**: 실험이 아니라 상관 관계였다. 더 쓸모 있는 결과는 "하다 만 추적은 안 한 것만큼 나쁘다"이다.
- **"80장 초안은 이미 완만하다"**: 난이도 숫자를 위치에 맞춰 매긴 순환 논증이었다.
- **"85% 정답률이 최적"**: 기계 학습 모델에 대한 이론이다. 운영 기준으로만 쓴다.

## 5. 정해야 할 것

조사로는 답할 수 없고 본인만 정할 수 있는 것이다.

| # | 질문 | 권장 |
|---|---|---|
| 1 | 작업장에서 폰·이어폰·종이를 언제 쓸 수 있나 | 확인 전까지 "폰은 휴식 때만"으로 설계. 오디오는 만들지 않음 |
| 2 | 폰 기종과 작업장 통신 상태 | 통신이 되면 서비스 워커 없이 시작. iPhone이면 홈 화면 추가와 내보내기 버튼을 1판에 포함 |
| 3 | 목표가 이해와 지루함 해소인가, 코딩 테스트까지인가 | 지금은 이해에 집중. 1판 뒤에 다시 결정 |
| 4 | 지금의 Python 수준 | 자기 평가 대신 1~4장의 추적 문제로 진단. 애매하면 1장부터 |
| 5 | 저장소 공개 범위와 호스팅 | 근무 패턴 노출이 걱정되면 비공개 저장소 + Cloudflare. 괜찮으면 공개 저장소 + GitHub Pages |
| 6 | 기존 자료를 어디까지 가져다 쓸 것인가 | 구조와 아이디어만 참고. 글·그림·코드는 전부 새로 생성 |
| 7 | 1판의 범위와 속도 | 종이 파일럿 3일 → 3장으로 틀 검증 → 14장까지. 주 2~3장 |

## 6. 다음 단계

1. 위 1번과 2번을 확인한다(사업장 규정, 기종, 통신).
2. 종이 카드 3장으로 3근무일 써 보고 기록한다([06](06-pilot-cards.md)).
3. 저장소 뼈대를 만든다: `CLAUDE.md`, `MISSION.md`, `curriculum.json`, `glossary.md`, 전용 스킬([02](02-skill-md-common-features.md) 6절).
4. 머지 전에 폰으로 볼 미리보기 경로를 정한다([05](05-tech-and-workflow.md) 8절).
5. 1장을 만들어 실제 폰으로 확인한다. 2장과 3장까지 만든 뒤 엔진을 동결한다.
6. 통과한 장 + 2 규칙으로 14장까지 간다. 14장 시점의 기록으로 15장 이후 순서를 확정한다.

## 8. 조사 방법과 한계

- **1차**: 9개 관점으로 나눠 조사했다(스킬 레지스트리, 알고리즘·시각화 스킬, 한국 커뮤니티, 시각화 사이트 24곳, 시각 교재 22곳, 모바일 학습 앱 19개, 학습과학, 커리큘럼 목차 약 50건, 구현 기술).
- **2차**: 스킬 36개의 원문을 다시 받아 33개 항목으로 점검했다. 계획을 좌우하는 주장 42건은 1차 자료로 반증을 시도했다. 빠진 조사와 조사 간 모순을 따로 점검했다.
- **3차**: 챕터 순서 초안을 두 관점에서 비판 검토했다. 파일럿 카드는 실행으로 만들고 독립적으로 다시 실행해 대조했다. 문서의 사실 관계를 검증 결과와 대조했다.

한계는 다음과 같다.

- 실제 폰으로 사이트들을 열어 본 조사가 아니다.
- 읽지 못한 곳이 있다(일부 스킬 레지스트리, Reddit 본문, solved.ac 등). 목록은 [07](07-sources.md) 6절에 있다.
- 버전, 날짜, 서비스 상태는 조사일 기준이다.
- 챕터 지도의 난이도 숫자와 임계값은 추정이다. 사람 교사의 검토를 거치지 않았다.
- 작업장에서 머릿속 재생이 실제로 되는지는 조사로 알 수 없다. 파일럿으로 확인해야 한다.
