# 교과서 장 만들기

## 이 교재

- Python 코드로 배우는 알고리즘·자료구조 **교과서**다. 읽는 사람은 한 명이고 Android 폰으로 읽는다.
- 교과서 형태다. 버튼, 애니메이션, 입력 칸 없이 위에서 아래로 읽으면 끝난다.
- 글보다 그림이 먼저다. 실행 과정은 단계별 정지 그림으로 전부 펼쳐 보인다.

## 장의 구성

모든 장은 아래 순서를 그대로 따른다.

1. **제목과 질문**: 장 번호, 제목, 이 장이 답할 질문 한 줄.
2. **개념**: 두세 문단. 무엇을 하는 알고리즘인지 말로 설명한다.
3. **코드**: Python 함수 하나.
4. **실행 과정**: 작은 입력 하나를 정해 처음부터 끝까지 따라간다. 단계마다 그림 한 장과 설명 한 줄을 붙이고 "그림 1, 그림 2, …"로 번호를 매긴다.
5. **정리**: 외울 문장 하나(불변식이나 공식)와 복잡도 한 줄.
6. **확인 문제**: 한두 개. 정답은 장 맨 끝에 둔다.

## 규칙

1. **한 장에 새 개념 하나.** 앞 장에서 다루지 않은 개념과 문법은 쓰지 않는다. 필요하면 그 내용을 다루는 장을 앞에 먼저 만든다.
2. **그림과 숫자는 실제 실행 결과만 쓴다.** 코드를 돌려서 얻은 값으로 그림과 정답을 만든다. 손으로 적지 않는다.
3. **예제는 작게.** 입력은 원소 4~5개, 단계 그림은 12장 이하. 넘으면 입력을 줄인다.
4. **폰 한 화면 기준.** 폭 360px에서 가로 스크롤이 없어야 한다. 코드는 15줄 이하, 한 줄 36자 이하. 문단은 세 문장 이하.
5. **색과 이름을 장마다 바꾸지 않는다.** 비교 중, 지금 고른 것, 자리가 정해진 것의 세 가지 색만 쓴다. 변수 이름(`i`, `j`, `lo`, `hi`, `mid`)과 용어도 앞 장과 같게 쓴다.
6. **한 번에 한 장만 만든다.**

## 끝내기 전에

- 코드를 실행해 그림의 값과 확인 문제의 정답이 맞는지 확인했는가.
- 360px 화면에서 가로로 넘치는 곳이 없는가.
- 이 장에서 처음 나온 개념이 하나뿐인가.
